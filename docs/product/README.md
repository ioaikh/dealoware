# product/

**Purpose:** Product goals, domain model, claims lock, and early platform additions — alignment source for all teams.

**Owners (triad):** Product Team — Chief Product → Senior Product → Product QA

**What belongs here:**
- CEO original specification (verbatim)
- Processed Product summary / goals / claims lock
- Domain model definitions
- Agreed early platform additions (facts already decided with Product/CEO)

**Do not invent** Product Stories or requirements here. Conflicts → escalate PM → Product → CEO.
