# Contributing to Dealoware

Thanks for contributing.

## Ground rules

- Code contributions are under the [Apache License 2.0](LICENSE).
- Do not commit secrets, credentials, or PII.
- Keep changes focused; open an issue for large design changes first when possible.
- The hosted Dealoware service is not this repo — PRs here improve the open-source core.

## How to contribute

1. Fork the repository
2. Create a feature branch
3. Open a pull request against `main` with a clear description and test notes

## Code of conduct expectations

Be respectful. Harassment and bad-faith contributions will be rejected.
