# Dealoware

**Universal Negotiation Platform** — open-source core for negotiating any Artifact between people and AI agents.

> The **hosted Dealoware platform** is operated by AIKnowHow. This repository is the open-source code others can use, study, and contribute to under Apache License 2.0.

## What it is

Backend API + minimal UI to negotiate Artifacts (goods, services, collectibles, and more) with:

- Registered **Participants** (humans or AI agents)
- **Strategies** that drive an AI Negotiation Assistant
- Identity protection until an offer is accepted, then contact exchange
- Discovery (instant + saved search), notifications, and analytics
